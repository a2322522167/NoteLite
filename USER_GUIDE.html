1快速开始

  1. 双击 NoteLite.exe（或开始菜单 → NoteLite）启动程序。
  2. 首次启动若未配置 DeepSeek API Key，会弹出引导窗口；可点击「稍后」或「不再提示」跳过，不影响其他功能。
  3. 主窗口出现后即可在左侧添加事件。
💡 提示：关闭窗口时默认 最小化到系统托盘，并不退出。要彻底退出请右键托盘图标 → 退出。

3添加事件

在左侧面板按字段填写，最后点 添加事件：

字段说明
事件描述任务标题/简述（必填）
+ 按钮（描述框右侧）选择附件文件（可多选；图片 / Excel / PDF / 文档等）
开始时间任务开始日期；点 📅 可弹出日历选择
截止时间任务截止日期；不可早于开始时间
优先级 高中低 决定卡片左侧色条颜色
添加事件点击后保存到「未完成」列表
✅ 小技巧：添加成功后输入框自动清空，方便连续添加多个事件。

4管理事件

每张事件卡片右下角有以下操作按钮：

按钮作用
完成把事件标记为已完成，自动记录完成时间，移到「已完成」标签页
撤回（已完成事件下出现）撤回到「未完成」
编辑弹出编辑对话框，可修改标题、时间、优先级、附件
附件（仅有附件时出现）查看 / 打开 / 定位附件
删除移入回收站（5 天后自动彻底删除）
⚠ 逾期提示：未完成且截止时间早于今日的事件，会在卡片信息行额外显示「逾期!」。

5拖拽排序

  • 每张卡片左侧有一个 ≡ 拖拽手柄。
  • 按住手柄或卡片标题向上 / 向下拖动，松开后即可调整顺序。
  • 排序在「未完成」与「已完成」两个 Tab 内 独立保存。
  • 顺序信息持久化，重启后保持不变。

6附件管理

添加附件

  • 添加事件 之前：点击事件描述框右侧的 + 按钮选择文件，状态会显示在下方"附件: xxx"。
  • 编辑事件时：在编辑对话框中点 ➕ 添加附件 / 清空附件。

查看附件

点击事件卡片的 附件 按钮，弹出附件列表：

  • 不同类型显示不同图标：🖼 图片 / 📊 表格 / 📕 PDF / 📝 文档 / 🎵 音频 / 🎬 视频 / 🐍 代码 / 📄 其他
  • 打开 — 用系统默认程序打开文件
  • 目录 — 在资源管理器中定位文件
  • 缺失文件以红色 ❌ 标注
📁 安全机制：所有附件会被复制到程序目录的 attachments/ 子目录，独立于源文件存放，删除原文件不影响附件。

7搜索与切换视图

  • 搜索：右上方搜索框，输入关键字实时过滤事件标题（不区分大小写）。
  • 未完成 / 已完成：上方两个 Tab 切换。

8滚动提醒条

顶部彩色横条会 自动横向滚动 展示所有「已开始未完成」的事件。颜色随状态变化：

✓ 全清
没有进行中的事件
▶ 进行中
事件在执行期内
⏰ 今日
今天截止的事件
⚠ 逾期
超过截止日期

右侧徽章显示「共 N 条」未完成事件数量。每条事件用 ● 分隔依次滚动。

9桌面卡片提醒

事件到达「开始时间」或「截止时间」后，桌面右下角会自动弹出 通知卡片：

  • 每隔 2 小时 提醒一次，共 3 次 后停止
  • 卡片 15 秒 后自动消失，也可点击 ✕ 立即关闭
  • 多张卡片自动堆叠不重叠
  • 提醒计数会被持久化，下次重启不会重复弹之前的提醒
💡 完成事件后，所有未触发的提醒立即作废，不会再打扰你。

10回收站

点击左侧 🗑 回收站 按钮：

  • 列表显示所有被删除的事件、删除时间、剩余保留天数
  • 恢复 — 还原到「未完成」列表
  • 彻底删除 — 立刻物理删除（含附件文件，不可恢复）
  • 清空回收站 — 一键彻底清空
⏳ 自动清理：回收站内事件 5 天后自动被永久删除（含附件文件）。

11本周总结 + DeepSeek AI 智能建议

📝 基础总结

点击左侧 本周总结 按钮，弹出窗口列出本周（周一 ~ 周日）的：

  • 已完成事件（含完成时间）
  • 未完成事件（含截止日期）

可点 一键复制 把全文复制到剪贴板，方便发周报。

🤖 AI 智能建议（DeepSeek）

  1. 在「本周总结」按钮 右侧 勾选 DeepSeek 复选框。
  2. 点击「本周总结」后，AI 会在窗口中追加：
    • 工作总结
    • 进展评估
    • 未完成事项的可行性建议与优先级排序
    • 下周计划建议
🔑 前置条件：需要在系统中设置环境变量 DEEPSEEK_API_KEY。
  • 应用首次启动时会引导你设置；也可手动添加。
  • 在 platform.deepseek.com/api_keys 申请 Key。
  • 设置完毕后 重新启动 NoteLite 才能生效。

12系统托盘 / 后台运行

  • 关闭主窗口（点 ✕）→ 最小化到系统托盘，程序仍在后台运行（提醒/计时正常工作）。
  • 右键托盘图标：
    • 显示窗口 — 唤回主界面
    • 退出 — 真正关闭程序

16常见问题 FAQ

Q1. 关闭主窗口程序为什么还在运行？

默认最小化到系统托盘，方便接收提醒。需要彻底退出请右键托盘 → 退出。

Q2. 设置了 DEEPSEEK_API_KEY 但 AI 总结仍提示未配置？

环境变量更改后需要 重启程序 才能生效；如果是在 cmd 里 setx，请关掉所有旧的 NoteLite 窗口再重新打开。

Q3. 提醒卡片没弹出？
  • 检查事件「开始时间/截止时间」是否已到
  • 同一事件每个时间点最多提醒 3 次
  • 完成或删除事件后不再提醒
Q4. 误删事件能恢复吗？

可以。打开 🗑 回收站 → 找到事件 → 点 恢复。5 天内有效。

Q5. 如何修改提醒间隔（2 小时）或最大提醒次数（3 次）？

编辑源码 notepad_app.py 顶部常量：

REMIND_INTERVAL_SECONDS = 2 * 60 * 60   # 提醒间隔（秒）
REMIND_MAX_TIMES = 3                     # 单事件单时间点最多提醒次数
TRASH_RETAIN_DAYS = 5                    # 回收站保留天数
Q6. 安装包安装向导是英文，应用本身呢？

应用界面是 中文，仅安装向导（Next / Cancel / Install）是英文。

Q7. 附件丢失怎么办？

附件物理文件存储在 attachments/。如该目录被移动或删除，事件附件按钮会显示「❌ 缺失」。请保持 attachments/ 与 events_data.json 在同一目录。

Q8. 程序运行需要安装 Python 吗？

完全不需要。NoteLite 是绿色发行版，已内嵌 Python 运行时和所有依赖，双击即用。
