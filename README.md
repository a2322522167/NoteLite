# 📘 NoteLite

一款面向个人效率管理的桌面智能记事本，支持任务管理、附件、回收站、桌面提醒与 AI 智能总结。

## ✨ 主要功能

- 📌 **任务管理**：添加、编辑、完成/撤回任务，支持高/中/低优先级
- 🔔 **智能提醒**：桌面右下角弹出通知卡片，2 小时间隔，最多提醒 3 次
- 📎 **附件支持**：可添加图片、文档、表格等文件，自动复制到程序目录，随事件管理
- 🗑️ **回收站**：误删事件保留 5 天，可恢复或彻底删除
- 🤖 **AI 智能总结**：基于 DeepSeek 生成周报总结、工作建议及下周计划
- 🎨 **主题切换**：暗色/亮色主题即时切换
- 🖱️ **拖拽排序**：任务卡片自由拖拽，排序自动保存
- 🔍 **搜索与视图**：按标题实时搜索，切换“未完成/已完成”视图
- 🧰 **系统托盘**：关闭窗口最小化到托盘，后台持续提醒

## 🚀 快速开始

1. 下载并解压 Release 包，双击 `NoteLite.exe` 启动。
2. 首次启动如有 API Key 配置引导，可“稍后”或“不再提示”跳过，不影响核心功能。
3. 左侧面板填写事件 → 点击 **添加事件**。
4. 试用更多操作：完成、编辑、附件、拖拽排序、回收站等。

> 💡 关闭窗口默认最小化到系统托盘，右键托盘图标可 **显示窗口** 或 **退出**。

## 🧠 AI 总结（DeepSeek）

1. 获取 API Key：[platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys)
2. 设置系统环境变量 `DEEPSEEK_API_KEY`，或使用首次启动时的配置界面。
3. 勾选 **DeepSeek** 复选框 → 点击 **本周总结**。
4. AI 将生成：
   - 工作总结与进展评估
   - 未完成任务建议与优先级重排
   - 下周计划建议

## ⌨️ 快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+N` | 焦点到“事件描述”输入框 |
| `Ctrl+F` | 焦点到搜索框 |
| `Ctrl+S` | 打开本周总结窗口 |
| `Ctrl+D` | 删除未完成列表的第一条事件 |

## 📁 数据存储

所有数据保存在程序所在目录，便于备份与迁移：

| 文件/目录 | 内容 |
|-----------|------|
| `events_data.json` | 所有未删除事件 |
| `trash_data.json` | 回收站事件（保留 5 天） |
| `attachments/` | 附件副本目录 |
| `.deepseek_skip` | “不再提示”标记文件 |

> ✅ 将以上文件及目录整体复制即可完成迁移。

## 🐛 常见问题

<details>
<summary>关闭窗口程序为什么还在运行？</summary>
默认最小化到系统托盘。请右键托盘图标 → <strong>退出</strong> 以彻底关闭程序。
</details>

<details>
<summary>AI 总结提示未配置 API Key？</summary>
环境变量更改后需要 <strong>重启 NoteLite</strong>。若仍无效，检查环境变量是否生效。
</details>

<details>
<summary>提醒卡片没有弹出？</summary>
- 确认事件的开始/截止时间是否已到达。<br>
- 同一事件同一时间点最多提醒 3 次。<br>
- 任务完成或删除后不再提醒。
</details>

<details>
<summary>误删事件能恢复吗？</summary>
可以。打开左侧 <strong>回收站</strong>，找到事件并点击 <strong>恢复</strong>。回收站内事件保留 5 天。
</details>

<details>
<summary>附件丢失怎么办？</summary>
请保持 `attachments/` 文件夹与 `events_data.json` 在同一目录。不要手动移动或删除该目录。
</details>

<details>
<summary>需要安装 Python 才能运行吗？</summary>
<strong>不需要。</strong> NoteLite 是绿色发行版，已内嵌 Python 运行时和所有依赖，双击即可使用。
</details>
